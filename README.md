# BPO-Customer-Support-Analysis
Customer Support Performance Analysis using Power BI

## Project Overview
This project focuses on analyzing customer support performance using Power BI. The dashboard provides insights into call volume, customer satisfaction, agent performance, and escalations.

## Tools Used
- Power BI
- Microsoft Excel
- DAX
- Data Visualization

## Dataset
The dataset contains customer support and call-related information used for analyzing service performance.

## Key Performance Indicators (KPIs)
- Total Calls
- Total Customers
- Average Call Duration
- Escalated Calls
- Customer Satisfaction

## Dashboard Insights
- Call Type Analysis
- Channel-wise Call Analysis
- Agent Performance Analysis
- Shift-wise Call Analysis
- Customer Satisfaction Analysis
- Escalation Analysis

## Project Files
- Customer_Support_BPO__Dataset.xlsx – Dataset
- BPO_Customer_Support_Dashboard.pbix – Power BI dashboard
- Dashboard_Screenshot.png – Dashboard preview

## Project Objective
To analyze customer support operations, track key performance indicators, and identify opportunities to improve service quality and customer satisfaction.

## Conclusion
This project demonstrates the use of Power BI to transform customer support data into meaningful insights through interactive dashboards and visualizations.
